# Vine B Digital (vinebdigital.com)

Modern high-performance website for **Vine B Digital** — a digital design and development agency crafting custom UI/UX, web applications, mobile apps, and scalable digital experiences.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Animations:** GSAP & ScrollTrigger, Framer Motion, Lenis Smooth Scroll
- **3D & Graphics:** Three.js / React Three Fiber

## Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
